# AgroRover X Wiring Diagram

## Arduino Uno to L298N

| Arduino Uno | L298N |
|---|---|
| D5 | ENA |
| D6 | IN1 |
| D7 | IN2 |
| D8 | IN3 |
| D9 | IN4 |
| D10 | ENB |

## Sensors and Indicators

| Arduino Uno Pin | Component |
|---|---|
| D2 | IR obstacle sensor OUT |
| D3 | Fake disease LED |
| D11 | Buzzer |
| D12 | Pump relay |
| D13 | Optional light |
| A0 | Soil moisture sensor AO |

## Fake Disease Alert

The LED connected to D3 and buzzer connected to D11 are demonstration indicators.

They do not perform actual crop disease detection. They represent a possible alert that could be generated by a future AI/ML model.

## ESP32-CAM Communication

| ESP32-CAM | Arduino Uno |
|---|---|
| TX/U0T | Arduino RX |
| GND | Arduino GND |

A voltage divider or level shifter should be used when connecting a 5V Arduino signal to a 3.3V ESP32 input.

## Pump

The water pump must be powered through a relay and a suitable external power supply. The pump should not be powered directly from an Arduino digital pin.
